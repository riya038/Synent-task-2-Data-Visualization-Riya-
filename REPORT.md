## Objective

The objective of this project was to analyze and visualize the Iris dataset using different visualization techniques to identify patterns and relationships among features.

---

## Dataset Information

The Iris dataset contains measurements of sepal length, sepal width, petal length, and petal width for different Iris flower species.

---

## Tools and Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## Methodology

1. Imported the Iris dataset.
2. Explored dataset characteristics.
3. Analyzed feature distributions.
4. Created various visualizations.
5. Compared different flower species.
6. Interpreted the generated visual insights.

---

## Visualizations Created

* Count Plot
* Histogram
* Scatter Plot
* Pair Plot

---

## Results and Findings

* Clear differences were observed among Iris species.
* Strong relationships were identified between petal dimensions.
* Visualizations made data interpretation easier and more effective.

This project demonstrated the importance of visualization in data science. Through graphical analysis, meaningful insights were extracted from the dataset, improving understanding of feature relationships and species characteristics.
