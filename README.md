# Iris Data Visualization Project

## 📌 Objective
The objective of this project is to visualize patterns and relationships in the Iris dataset using different charts and graphs.

## 📂 Dataset
Iris Dataset from Kaggle.

## 🛠 Tools & Libraries Used
- Python
- Pandas
- Matplotlib
- Seaborn
- VS Code

## 🔍 Steps Performed
1. Loaded dataset
2. Checked dataset information
3. Verified missing values
4. Created different visualizations
5. Compared features of flower species

## 📊 Visualizations Created
- Species Count Plot
- Sepal Length Histogram
- Scatter Plot
- Pair Plot

## 📈 Key Insights
- Iris-setosa species is clearly distinguishable from others
- Petal length and sepal length show strong relationships
- Dataset is balanced across species
- Visualization helps understand species distribution easily

## ✅ Output
Successfully created meaningful visualizations and feature comparisons using the Iris dataset.
